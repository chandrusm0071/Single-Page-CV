# Chandru S M - Single Page CV

A clean, professional, and modern single-page CV built with HTML and CSS. This CV showcases professional experience, technical skills, projects, and education in a visually appealing format.

## 🎯 Project Overview

This is a responsive, print-ready CV that displays information in a minimalist design with green accent colors. The layout is optimized for both web viewing and PDF printing.

**Key Features:**
- ✅ Clean and professional design
- ✅ Responsive layout for all devices
- ✅ Print-optimized styling
- ✅ Green accent color scheme
- ✅ Easy to customize
- ✅ All information on a single page

## 📋 Contents

- **Personal Information** - Name, contact details, and professional title
- **Skills** - Programming languages, tools, and core competencies
- **Education** - Academic background and qualifications
- **Professional Experience** - Internship details and achievements
- **Projects** - Notable projects with descriptions
- **Certifications & Activities** - Professional certifications and leadership roles

## 🚀 How to Run

### Option 1: View in Browser (Recommended)

1. **Clone or Download the Project**
   ```bash
   git clone https://github.com/chandrusm0071/Single-Page-CV.git
   cd Single-Page-CV
   ```

2. **Open the HTML File**
   - Simply double-click the `index.html` file, or
   - Right-click → Open with → Your preferred browser

3. **View in Live Server (VS Code)**
   - Install the "Live Server" extension in VS Code
   - Right-click on `index.html`
   - Select "Open with Live Server"
   - The CV will open in your default browser

### Option 2: Using Python Server

**Python 3:**
```bash
python -m http.server 8000
```

**Python 2:**
```bash
python -m SimpleHTTPServer 8000
```

Then open `http://localhost:8000` in your browser.

### Option 3: Using Node.js

Install `http-server` globally (if not already installed):
```bash
npm install -g http-server
```

Run the server:
```bash
http-server
```

Open the URL shown in your terminal (typically `http://localhost:8080`).

## 🖨️ Print to PDF

1. Open the CV in your browser
2. Press `Ctrl+P` (Windows/Linux) or `Cmd+P` (Mac)
3. Select "Save as PDF" as the destination
4. Choose "A4" size for standard paper
5. Click "Save"

## 🎨 Customization

### Change Personal Information
Edit the following sections in `index.html`:
```html
<div class="name">Chandru S M</div>
<div class="title">Python Developer & ML Engineer</div>
```

### Modify Skills
Update the skills section:
```html
<strong>Programming:</strong> Python, MATLAB, JavaScript, HTML, CSS
```

### Change Color Scheme
Replace `.2ecc71` (green) with your preferred color throughout the CSS:
```css
.title {
    color: #2ecc71;  /* Change this to your color */
}
```

### Add or Remove Sections
Simply add or duplicate section blocks as needed:
```html
<div class="section">
    <div class="section-title">Section Name</div>
    <!-- Add your content here -->
</div>
```
